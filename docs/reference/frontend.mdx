The web app is React, TanStack Start, TanStack Router, TanStack Query, Tailwind CSS, and shadcn components built on Base UI. [Product](/product) describes each screen, and [Design](/design) describes the visual language.

## Routes

| Route             | Screen                                                                                                                      |
| ----------------- | --------------------------------------------------------------------------------------------------------------------------- |
| `/`               | Overview for the selected period.                                                                                           |
| `/spending`       | Category breakdown. `?category=` drills into a subtree.                                                                     |
| `/ledger`         | Transactions. `/ledger/$id` opens one posting with its meaning and evidence.                                                |
| `/counterparties` | Counterparties paid or paid by in the period. `/counterparties/$counterpartyId` opens one.                                  |
| `/questions`      | Computed questions, records to check, and movements to confirm. `?importId=` narrows to a file.                             |
| `/sources`        | Upload, imports that need you, coverage, files, and exports. `/sources/imports/$importId`.                                  |
| `/settings`       | Accounts, account history, identification, model usage, display, and backups. `/settings/categories` and `/settings/rules`. |

Three server routes pass requests through to the API's HTTP handler without rendering a screen. `POST /uploads` forwards an upload with its headers and body. `GET /sources/$sourceFileId` returns an original file, and `GET /exports/$exportId` returns an export's ZIP.

The top bar links to Overview, Spending, Ledger, Counterparties, Sources, Questions with its open count, Settings, and Upload. On a phone, the menu holds the destinations and Settings.

The period strip shows on the overview, spending, ledger, and counterparties. Its bars select a month and its year labels a calendar year. Choose months, at the end of the strip in `src/components/shell/month-range-picker.tsx`, selects a range of whole months with two selects in a popover, and the strip inks every month in the range. Without a `?period=`, those screens read the current month in the settings timezone, or redirect to the latest month with records when this month has none yet. The overview and spending show `ComparisonControl` from `src/components/comparison-control.tsx` under their titles, and `ComparisonCoverageNote` from `src/components/comparison-coverage.tsx` under it. The control's trigger is named for what it does, "Compared with August 2026. Choose another comparison", so it is not mistaken for a strip link to the same month. Its popover offers the period before, the same period last year, and chosen dates on a two-month calendar, and Compare applies the choice. A period of twelve months leaves out last year, because it covers the same dates as the period before. The calendar offers days from the first month with records through today in the settings timezone, marks that day as today, and disables every later day. Both popovers render their heading with `PopoverTitle`, which names the dialog. The calendar selects local-midnight `Date`s, so dates cross in and out of it through local date parts, never through UTC. Its day button in `src/components/ui/calendar.tsx` attaches the focus ref that the shadcn registry version leaves unattached, so the arrow keys move through the days. Adding the calendar again with the CLI undoes this.

Route modules own URLs and loaders. Feature modules under `src/features/` own server functions, query options, and views. Shared controls live in `src/components/ui`, and application-level components such as the period strip, amounts, and provenance marks live in `src/components/`.

## Design tokens

`src/global-styles/tailwind.css` defines the palette as CSS variables and maps them to Tailwind colors and to shadcn's semantic tokens: `background` is Polymer, `card` and `popover` are Sheet, `foreground` and `primary` are Intaglio. Components use the semantic names. Inflow, outflow, and attention are their own tokens: `inflow`, `outflow`, and `attention`. Category hues come from `src/lib/category-colors.ts`, keyed by top-level category slug.

Archivo is loaded from `@fontsource-variable/archivo` with its width axis. Text styles are Tailwind utilities that set width through `font-stretch`: `type-figure`, `type-figure-s`, `type-title`, `type-heading`, `type-body`, `type-small`, and `type-condensed`. Figures and `tabular` enable `tabular-nums lining-nums`.

## State

The period, the comparison, filters, and drill-down path live in validated search parameters, so the back button and bookmarks restore a view. `src/lib/period.ts` defines both keys as Effect schemas:

| Parameter   | Values                                                                                                                                                         |
| ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `?period=`  | A month, `2026-08`. A calendar year, `2026`. A range of whole months, `2026-03..2026-05`.                                                                      |
| `?compare=` | `lastYear` for the same period a year earlier, or chosen dates, `2026-03-01..2026-04-14`, both days included. Without it, the comparison is the period before. |

TanStack's search parser reads a typed `?period=2026` as the number 2026, so the year key also decodes an integer. Ranges must not run backwards, and months and dates must exist. A period key is also refused when its months, the months before them, or the same months a year earlier would fall outside years 0001 to 9999, so every comparison the screens name can be resolved. The root route validates both parameters and keeps them on every navigation with `retainSearchParams`. Setting one to `undefined` removes it. `periodKey` writes chosen months as the shortest key: a single month, a calendar year, or a range.

`resolvePeriodKey` turns a key into its first and last month. Without a key, it takes `currentMonth` in the settings timezone, which Sources also uses to end the whole history. `currentMonth` and the comparison calendar read `today` in the settings timezone, and period resolution reads no other clock. `flowInput` sends the months as `{ kind: "months", from, to }`, with the comparison from `comparisonSelection` and the spending date. The API decides whether the last month is still in progress, so the result, not the browser's clock, says how many days a period has so far. Titles come from `periodLabel` and `monthLabel` in `@repo/finance`. `wholeComparison` gives the whole months a comparison covers, which the control's trigger and options name, so September in progress compares with "the same days of August 2026". Every sentence that states or compares an amount names the dates the result compared, `periodLabel` of its `comparison`: "$310 more than in August 2026" for a whole month, and "$310 more than in 1 to 25 August 2026" while September is in progress, so a partial total never carries a whole month's name.

Query keys are the operation name plus its normalized input. Loaders call `ensureQueryData` so a route renders with data.

Server functions call the API through the typed binding. They validate input with the contracts schemas first. `callApiRpc` in `src/server/api-client.server.ts` creates the stub with `makeRpcStub(env.API, { errors: [FinanceError] })`, so a `FinanceError` arrives with its kind and message, and it times each call out after 10 seconds as `unavailable`.

## Commands

A write generates a `commandId` with `crypto.randomUUID()` when you confirm, sends it with the expected versions, and shows a pending state until the server responds. On a network failure, Retry resends the same `commandId`. On `stale`, the form keeps your input, shows the current record, and asks again. On success, most writes call `client.invalidateQueries()` with no filter, so every cached query refetches. Uploads, import completion, and source review decisions do the same. A few writes invalidate only the queries they name: display settings, account edits, source removal, export requests, and import retry. A `stale` failure also invalidates every query.

A change that affects money shows a preview first: the affected records, their versions, and the financial impact. Accepting sends those versions.

## Amounts

`src/components/amount.tsx` renders every money value from its `Money` minor units through `formatCurrency` in `@repo/finance`, never from a float. Outflows show a minus sign and inflows none. The value's color comes from its direction only in the flow and the headline. Tables use Intaglio for every amount so a column reads evenly.

## Charts

The flow diagram uses Recharts' `Sankey` directly, with custom node and link renderers, in `src/features/overview/flow-diagram.tsx`. Below the `md` breakpoint it shows bars instead. It has a text summary, a screen-reader table, and a button that shows the table in place of the diagram. The other charts, such as the spending bars and 12-month sparklines, are hand-built HTML and SVG with screen-reader text and no table view. Chart coordinates may be floats; displayed amounts come from the result's `Money` values.

## Accessibility

Every action works at 390 pixels wide and by keyboard. Focus returns to the triggering control when a dialog closes. A transaction's detail is its own route, `/ledger/$id`, not a sheet. Provenance marks and flow streams have text equivalents. A global rule in `src/global-styles/tailwind.css` shortens every animation and transition to 0.01 ms when reduced motion is preferred, which covers the flow's reveal. Tables of amounts scroll within their container rather than the page. A horizontal scroller is `relative`, so the absolutely positioned `sr-only` text inside it cannot widen the page.
