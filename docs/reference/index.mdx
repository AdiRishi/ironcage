## Platform

Effect, Alchemy, Cloudflare Workers, TanStack Start, and shadcn. PlanetScale Postgres through Hyperdrive for financial records, R2 for original files, Cloudflare Workflows for imports, enrichment, and exports, and the Workers AI binding with AI Gateway for models. Library versions come from the pnpm catalog and lockfile.
