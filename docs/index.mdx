## How to read these docs

Choose a [stage](/stages) and follow its reading path. [Build one stage](/technical/build-spend-management) explains implementation and completion. Stage 1 is the default target. The references retain the eventual spend-management plan without making it an obligation for every task.

The [vision](/vision) explains the broader purpose. The docs describe intended behavior, not a claim of shipped functionality. Each stage must produce a working browser experience backed by real records. [Acceptance scenarios](/product/acceptance) identify the stage that introduces each outcome.

Visual branding and screen composition are unspecified. Stage flows provide the written brief for subsequent design work.

All monetary examples are fictional. Private bank statements, identifiers, and transaction histories stay outside this documentation site.
