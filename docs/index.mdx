Ironcage imports CommBank exports and statements, records every posting once with its evidence, and interprets it. It identifies who each payment went to, what it was for, and whether it was spending at all. Then it explains where money came from, where it went, and what changed.

It runs on Cloudflare and is developed locally against the real corpus. It has not been deployed.

## How to use these docs

[Operations](/reference/operations) is also the runbook for hosted stages, so it lists checks that have not been run yet.
