Ironcage is a private personal finance application for one user. Its current scope is a complete spend-management experience: a coherent financial history, detailed trends, forecasts, and an analyst that remembers useful context.

## How to read these docs

The product pages specify intended behavior. The technical pages describe the target implementation, rather than features already shipped. The [acceptance scenarios](/product/acceptance) define observable outcomes for the complete spend-management scope.

The [design section](/design) contains visual references for the product flows, including corrections, incomplete data, and recovery states.

An implementation agent starts with [Build spend management](/technical/build-spend-management). That guide explains how to use this specification, resolve remaining engineering choices, and establish completion without the discovery conversation.

All monetary examples in these pages are fictional. Bank statements, account identifiers, and transaction histories belong in private application storage, not in this documentation site.
