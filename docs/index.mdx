Ironcage is a private personal finance application for one user. It imports CommBank exports, records every posting once with its evidence, and builds understanding on top: what things mean, how spending changes, what an ordinary month costs, what is coming, and what changed. Nothing has shipped yet. These docs describe what to build.

## How to read these docs

An implementer reads [Starting point](/stages/starting-point), then the selected stage page, then the reference pages that stage names. Stage 1 is the default. The [glossary](/glossary) fixes the vocabulary.

The [Design section](/design) contains the screen designs for each stage.

The [vision](/vision) explains why the application exists.
