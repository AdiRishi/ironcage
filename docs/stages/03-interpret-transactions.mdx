## Outcome

Add financial meaning above recorded postings, with direct user control.

Prerequisite: Stage 2 is verified. Earlier postings can be interpreted without reupload.

## User flows and frontend

- Inspect roles, categories, merchants, splits, tags, personal events, and evidence beside the original bank fields.
- Confirm transfers, card settlements, borrowing, repayments, and missing counterpart evidence without inventing bank postings.
- Link partial refunds and reimbursements and preview their effect on financial measures.
- Edit one interpretation, preview broad rules, preserve individual exceptions, inspect change history, and undo through a new correction.
- Request category suggestions for existing records, accept them individually or in bulk, or categorize manually when the model fails or is uncertain.

The stage is complete only when these flows use real persisted records and work on desktop, mobile, and with a keyboard. Empty, loading, review, and failed states belong to the same implementation.

## Backend and integration

Introduce events and conserving allocations now, leaving still-uninterpreted postings visible. Apply user corrections and accepted rules before model suggestions. Financial roles require evidence or explicit confirmation; unknown categories on established costs remain unclassified.

Implement financial measures for details and previews, credit limits, version-checked changes, and correction history. Use a bounded SDK classification call with validated category choices. Interpretation is requested independently from import and may rerun; accepted user decisions cannot be overwritten. Extend data export to these records.

## Completion evidence

Demonstrate card settlement, internal transfer, refund, reimbursement, and mortgage examples through details and previews. Verify split conservation, credit limits, conflicting edits, rule exceptions, and undo. Categorize earlier history, then import overlapping statements without changing posting identity or accepted corrections.

Exercise unavailable and invalid model responses through the manual categorization flow. Check representative suggestions and their supporting evidence without mandatory confidence scores or labeling quotas.

Preserve earlier stage regressions and report specific unverified external checks. Stop after this stage.

## Excluded

Historical comparison screens, saved analyses, ordinary-cost estimates, schedules, forecasts, analyst conversations, and findings.
