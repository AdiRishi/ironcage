## Outcome

Extend the working importer to PDF statements and source-data controls.

Prerequisite: Stage 1 is verified. Reuse its posting identities and review flow.

## User flows and frontend

- Upload PDF statements alongside structured exports and inspect page evidence for a questioned row.
- See one posting supported by several formats and resolve genuine cross-format ambiguity.
- Export financial records and evidence relationships, optionally with original files, and download the result. Retry an export that fails.
- Confirm removal of original file bytes. Keep transactions and extracted fields, mark the file unavailable, and restore source access by reuploading the same bytes.
- If document AI is needed, inspect its provider, usage estimates, and limits, or resolve the uncertain evidence manually.

The stage is complete only when these flows use real persisted records and work on desktop, mobile, and with a keyboard. Empty, loading, review, and failed states belong to the same implementation.

## Backend and integration

Use unpdf with verified CommBank layouts. Validate every actual PDF, including the visible pages needed to establish repairs. Model assistance is a bounded optional extraction path for demonstrated document needs; no rendering runtime is prescribed in advance.

Extend the same atomic publication and deterministic matching rules to PDF. Add on-demand exports and source-byte removal. Keep the bank records independent of categorization. Model failure leaves a specific review item without damaging earlier imports.

## Completion evidence

Account for every supplied file and check cross-format overlaps in different orders. Validate PDF dates, amounts, balances, and row completeness against visible statement evidence. A specific missing fact can require review; a parser defect or blanket review state is not completion.

Demonstrate export/download, failed-export retry, removal with one or several supporting sources, and reupload without new postings. If models are used, verify invalid output and provider failure with manual resolution. Verify the actual deployed extraction path.

Preserve earlier stage regressions and report specific unverified external checks. Stop after this stage.

## Excluded

Categorization, interpretation records and relationships, spending analysis, planning, analyst conversations, and findings.
