## Outcome

The same upload and transaction-history application accepts all supplied CommBank CSV, OFX, and PDF files. The user can inspect older statement evidence, resolve extraction issues, export recorded data, and explicitly remove a source.

Prerequisite: stage 1 is verified. Extend its import pipeline, review flow, and transaction identities.

## User flows and frontend

- Upload PDF statements alongside structured exports. Show page-related extraction progress and the existing per-file outcomes.
- Inspect statement pages and extracted rows when a value, account, or match needs review. Distinguish observed coverage, reconciled intervals, confirmed inactivity, and missing evidence.
- See one bank posting supported by several formats. Retain access to every supporting observation and its source.
- Request an export with optional original files, follow its background progress, and download the completed package.
- Preview source removal. Identify transactions with surviving evidence and let the user retain unsupported records with a warning or withdraw them. Reupload restores evidence; returning withdrawn records requires an explicit undo preview.
- Inspect model providers, retention, usage limits, reservations, and uncertain charges for document extraction. Change a limit and retry unfinished extraction while accepted records remain usable.

Use the existing Imports, Review, Transactions, and Settings experiences. Source-removal previews show affected records and evidence availability. Financial impact measures arrive with interpretation in stage 3; no spending impact is fabricated here.

## Backend and integration

Add the selected unpdf adapter and versioned CommBank layouts. Render ambiguous or scanned pages through the document-processing Container where required, with structured model proposals and independent financial validation. Add shared model policy, AI Gateway routing, usage reservations, and document evaluation without an analyst runtime.

Extend reconciliation and coverage to the full corpus. PDF observations attach to existing canonical postings. Corrected extractors preserve accepted evidence decisions. Roles remain unresolved and categorization is not dispatched.

Implement user export, source-removal fencing, retention/withdrawal, evidence restoration, and undo of source withdrawal. Reuse stage 1 backup/export internals. Extend backup and restore coverage to extraction artifacts and model accounting. Conversation export remains absent until stage 6.

## Completion evidence

Account for every supplied CSV, OFX, and PDF file and reconcile the full corpus across formats and import orders. Compare extracted amounts, dates, and balances with independently checked statement evidence. Specific unresolved records are permissible only for missing or conflicting evidence; broad review output does not excuse parser defects.

Exercise PDF review, model-limit recovery, export download, source removal with surviving and last-source evidence, reupload during and after removal, and explicit withdrawal undo through the UI. Verify rendering in the hosted runtime and restore the expanded backup format.

## Excluded

Financial-role establishment, category models, merchant normalization, semantic relationship review, spending analysis, commitments, forecasts, analyst conversations, and proactive findings. Document extraction may use AI; the user-facing analyst does not exist yet.
