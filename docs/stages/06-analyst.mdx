## Outcome

Add one conversational agent using the financial application already built.

Prerequisite: Stage 5 is verified. Analyst tools reuse existing financial read operations.

## User flows and frontend

- Start or reopen a conversation and ask about history, a selected record, a comparison, or a scenario.
- Inspect tool results with calculation time, coverage, and links to supporting records.
- Answer clarifications and accept proposed changes through existing edit controls or explicit confirmation cards.
- Manage explicit personal notes. After changing or removing a note, continue in a fresh conversation and retain the old one for inspection.
- Reconnect using SDK-supported message/stream recovery, stop an answer, or ask again after failure. Inspect available usage estimates.

The stage is complete only when these flows use real persisted records and work on desktop, mobile, and with a keyboard. Empty, loading, review, and failed states belong to the same implementation.

## Backend and integration

Use AIChatAgent persistence and streaming with a normal bounded SDK tool loop. Authenticate owner-bound namespace routing. Financial tools are read-only; user acceptance invokes the existing financial command. Allow one active answer per conversation.

Keep notes explicit and use current domain records for account roles and rules. Do not add a parallel run supervisor, textual-edit authorization parser, child agents, or arbitrary computation runtime. Conversation storage follows the SDK lifecycle independently of managed financial backups.

## Completion evidence

Compare numerical answers with independently verified API results. Follow source links, resolve a clarification, accept a suggested edit, and reject a stale edit. Test provider failure, stop, and reconnect through the actual SDK integration. Demonstrate a note removal followed by a fresh question without the old transcript. Verify unauthenticated access fails and source/model text cannot authorize writes.

Preserve earlier stage regressions and report specific unverified external checks. Stop after this stage.

## Excluded

Custom investigation recovery, automatic financial writes from text, child agents, generated scripts, synchronized chat/database backups, and proactive findings.
