---
title: Analyst and memory
description: Ask questions, get evidence, keep explicit notes.
---

Everything here is stage 6. The screens already answer these questions; the analyst answers them in conversation.

## Answers with evidence

Ask a question, or ask about a selected posting, chart, or scenario. The analyst uses the same calculations as the screens and shows its numbers with period, accounts, basis, coverage, calculation time, and links to the records. It separates what the records show from what might explain it. Missing card data is a gap, not a drop in spending. When it cannot answer, it says what is missing.

## Proposed changes

The analyst can suggest a correction. It opens the normal edit control or shows a card with the proposed change. Nothing changes until the user accepts, and acceptance goes through the same checks as any other edit. If the record changed in the meantime, the user is asked again.

Text cannot make changes. A bank description that reads like an instruction is just a description.

## Notes

The user can save notes for the analyst, optionally tied to an account or a period: "August has a house guest", "the Kellyville transfers are rent". Notes are the only memory. Account settings, personal events, and rules stay where they are. Nothing said in conversation becomes a fact on its own.

Editing or removing a note starts a fresh conversation for what comes next, so the old wording cannot leak back in through the transcript. The old conversation stays readable. The dialog says this before confirming.

## Conversations

Conversations persist. One answer runs at a time; the user can stop it. Closing the browser and coming back shows what was there. A failed answer can be asked again, which may cost another model call. Old answers keep their text and calculation time; their links open live records.

## Example

From Trends showing dining up in August, the user asks why. The analyst lists the top merchants with the delta and links. The user says the 14 August dinner was for work; the analyst shows a card to mark it non-personal, the user accepts, and the event updates. The user saves a note about the August house guest. Later the user deletes the note and the next question runs in a new conversation without it.
