Navigation shows what exists. There are no disabled menu items or coming-soon screens.

## State in the URL

Filters, periods, comparisons, and selected groups are in the page URL. The back button returns to the previous view. A bookmark reopens the same question against current data.

## Home

Before the first import, Home explains which files to upload and how to get them from NetBank. After it, Home shows the latest import date, coverage per account, and from stage 4 the current month's overview, from stage 5 upcoming commitments, and from stage 7 open findings.

## From a number to its records

Any number can be opened. From stage 4, opening a contributor shows its records with the same period, basis, and filters, and each record shows what it contributed beside what the bank booked. Coming back restores the view. From stage 6, asking the analyst about a selection carries that selection into the conversation.

## Pending, failed, and stale

A change shows as pending until the server confirms it. A failed request keeps the user's filters and unsaved input and offers retry. If the record changed under the user's feet, the app shows the current version and asks again rather than overwriting. A view never shows a total from before a change beside rows from after it.

## Screen sizes and input

See the [screen designs](/design) and [mobile layouts](/design/responsive).

Everything works at phone width and by keyboard. Nothing depends on hover. Every chart has a text summary and a table. Color always has a label. Reduced-motion settings are respected.
