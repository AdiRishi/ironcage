## Accounts

Each account has a label and a kind: deposit, card, or loan. Bank identifiers appear once a file has established them. From stage 3, an offset relationship between a deposit account and the loan can be recorded with the dates it applies, and a label can change from a date.

## Display

Timezone defaults to Australia/Sydney and currency to AUD. They affect how things are shown and grouped, never what the bank booked. A single-currency view names the currencies it leaves out rather than converting them.

## AI

Settings names the provider, says which records each task sends, and shows usage and cost so far, with unknown usage marked unknown when a failed call reported nothing. AI can be switched off; imports and every screen keep working. A spending warning stops new calls once observed usage reaches it, with the caveat that late reports and calls in flight can push past it.

## Export

From stage 2, an export is a download of all financial records and their evidence links, with the original files as an option. It names what it contains and when it was made. If it fails, ask again. It is a data download, not a backup of the whole system.

## Source files

Each original file can have its bytes removed. The confirmation lists the postings the file supports and says only the original bytes go: postings, extracted rows, and corrections stay. The file shows as unavailable afterward. Uploading the same bytes again restores it without adding anything.

If storage deletion fails, the app shows the failure and offers Retry. Retrying the earlier removal leaves any replacement upload intact.

## Retention

The page states how long database backups are kept and where a second copy of original files lives. Removing a file or a note removes it from the app, not from backups already taken.
