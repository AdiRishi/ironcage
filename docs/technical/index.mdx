The design extends the existing Alchemy and Effect application platform. Financial records and calculations belong to application services. The AI analyst uses those services through typed tools, and the web app uses the same services for its views.

:::note
These pages define the target implementation. Module locations, schemas, routes, and runtime behavior describe the design to build, not a claim of shipped functionality.
:::

To implement the product, start with [Build spend management](/technical/build-spend-management). The guide connects these references to the work and its completion criteria.

## Design status

Cloudflare, the existing starter, TanStack Start, shadcn components, Cloudflare Agents SDK, AIChatAgent, Vercel AI SDK, Workflows, and AI Gateway are selected.

The data structures and policies in these pages are implementation decisions derived from the [product contract](/product). Their correctness is established through the [acceptance scenarios](/product/acceptance), not by the presence of a framework feature.

Model IDs and operating limits are configuration selected through evaluation. They are not guessed version pins in these docs. The package catalog and lockfile remain the source of installed dependency versions.

The technical foundation supplies strong types, Effect services, Alchemy infrastructure, and Cloudflare Worker RPC. These pages describe the financial application built on that foundation.
