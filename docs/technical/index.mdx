## Platform

Effect, Alchemy, Cloudflare Workers, TanStack Start, shadcn. PlanetScale Postgres through Hyperdrive for financial records. R2 for original files. Cloudflare Workflows for imports and exports. `AIChatAgent` for stage 6. Library versions come from the pnpm catalog and lockfile; model IDs are chosen when the feature that uses them is built.
