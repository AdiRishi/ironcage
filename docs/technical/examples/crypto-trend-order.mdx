This is the canonical trace of the fixed trade referenced throughout [The tick](/technical/the-tick), [Venues](/technical/venues), and [AI](/technical/ai). Every ID, timestamp, and amount here is canonical; the chapters quote fragments of this file.

:::note
This trace is a **fixture replayed through a scripted venue adapter**. The venue actor runs its real code, but its "venue" is a script that feeds it recorded responses: an acknowledgment, a partial fill, and a window-expiry cancel. The script is what lets one trace exercise partial-fill handling, stop resizing, and the reservation split. It is not produced by the dry-run fill model: that model fills or expires an order whole and has no liquidity model to determine a partial quantity ([Venues](/technical/venues), open question 5). The integration test replays this file against the scripted adapter and requires byte-identical rows. Rows are tagged as [Data](/technical/data) defines: the book is the fixture's book (`dry_run`), every fill carries `simulated = true`, and `fill_model` names the script rather than the fill model.
:::

## Variant: born rejected

At the `08:00:15Z` alarm the same sleeve, holding the A$600 position, desires `Enter BTC/AUD A$10,000`. The regime output from the `04:00Z` schedule is fresh (`valid_until 10:00Z`), so the clamp yields 10,000 × 0.5 = A$5,000. The position-size check fails: `600 existing + 0 in-flight + 5,000 proposed = A$5,600 > A$5,000`, distance −600. No reservation is requested and no venue call is made; the system cage and the venue actor never hear of this intent.

The rejection is still a complete record. After the in-flight marker, one Postgres transaction commits: the `(crypto-trend, 08:00)` tick outcome, the intent row `018f6b3c-2e15-7f08-a941-6c0d5b8e2f74` in state `rejected` (with its full `decision_context` and `cage_verdict`), its single `intent_transitions` row (seq 1, `rejected`, writer `sleeve_actor`), and an `intent_rejected` feed event (notice) whose payload carries the full verdict. The marker is then cleared; the state is terminal at birth. Because the intent never reached the venue, it consumes no trade-frequency budget: the next entry attempt is still 2 of 6, not 3.
