## Access

Production runs at `wealth.arishi.dev` under the existing `arishi.dev` zone. The web module in `infra/src/web-application.ts` owns the domain and the Cloudflare Access application. Access allows exactly one identity. Staging gets its own hostname and Access application before it goes live.

The web Worker validates the Access JWT on every request: signature against the team's public keys, issuer, audience, and expiry. [Access token validation](https://developers.cloudflare.com/cloudflare-one/access-controls/applications/http-apps/authorization-cookie/validating-json/). Internal Workers have no public hostname. Mutation handlers also check the request origin.

## Database

PlanetScale Postgres, reached from the API through a Hyperdrive binding with query caching disabled. Effect SQL with the existing composition. A database transaction uses one connection for its whole life. Separate application and migration roles, TLS, and secrets in the stack. Local development, CI, and tests use a disposable local Postgres of the same major version with the same migrations.

Production, staging, and test stages have separate databases and buckets. Choose region, size, and plan when provisioning, from the measured workload.

## Workflows

Imports run as `ImportWorkflow` instances with a small number of steps and the platform's retry policy. The processor exposes instance status to the API. Input size and step timeouts are configured from the corpus measurements. Measure the largest file's publication before changing the design.

## Backups and retention

Enable PlanetScale's managed backups and point-in-time recovery, and record the retention period. [Back up and restore](https://planetscale.com/docs/postgres/backups). Database backups do not include R2 objects, so keep an independent copy of every original file outside Cloudflare, either the user's own archive or a second bucket. Record where that copy lives.

Before the first private import, restore a backup into an isolated stage and confirm postings and review resolutions are present and original files can be retrieved from the independent copy. The settings screen states the retention period and the independent-copy arrangement. Source and note deletion remove data from the live system, not from retained backups, and the screen says so.

Temporary export objects expire on a lifecycle rule. Lifecycle rules never touch the sources bucket.

## Exports

From stage 2, an export is a zip containing JSON files per record type plus a manifest naming the format version, included record types, counts, and time. Original files are an optional addition. Large exports run as a Workflow and produce a temporary download. A failed export is requested again.

## Models

Configured through the AI SDK and the existing provider integration. Settings names the provider and what each task sends. Routing through a gateway does not keep inference inside Cloudflare, and the settings text does not claim it does. [AI](/technical/ai) owns limits, usage records, and the on/off control.

## Scheduled work

Stage 7 adds a cron trigger on the processor that runs the finding scan, intention reviews, and import reminders. Each run reads current data and writes findings by stable identity. Nothing else is scheduled.

## Observability

Log operation IDs, import IDs, Workflow instance IDs, timings, and error kinds. Never log prompts, completions, descriptions, or account numbers. Workers observability and PlanetScale metrics are the diagnostic tools.

## Deployment

Alchemy owns the resource graph. Migrations are versioned SQL under `workers/api/migrations/` and run from an empty database and from a populated one. A migration that old code cannot read ships with a coordinated deploy after a verified backup.

Before the first private deployment, confirm: Access blocks an unauthenticated request, a source download requires the session, a repeated upload creates nothing, a lost command response is recovered by its ID, and the restore drill above has been performed. Stage 6 adds: the analyst WebSocket rejects a request without identity.
