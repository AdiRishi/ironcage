# Decision archive

This is history, not specification. Each entry records that a choice was made, when, and where the current design now lives. The reasoning and the rejected alternatives live inline in each chapter's "Alternatives considered" section. If a chapter and this archive disagree, the chapter wins and the archive gets a superseding entry — never a silent edit. You never need this file to build the system; you need it to avoid re-arguing settled questions.

Entries D1–D28 date from the original specification (2026-08, iteration phase). D29 onward were recorded during the 2026-08 consolidation, which reviewed five independent rewrite attempts and adopted the strongest mechanics from each.
