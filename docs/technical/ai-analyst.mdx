The analyst arrives in [stage 6](/stages/analyst). Earlier stages already provide uploads, records, corrections, comparisons, and planning through their own screens. The analyst adds a conversational way to use those capabilities.

## Runtime

Use AIChatAgent in the analyst-owned Durable Object. The public web Worker authenticates and routes SDK HTTP/WebSocket traffic through the private namespace binding. Instance identity comes from the authenticated owner. The analyst validates that connection identity before serving messages or invoking financial tools.

The SDK owns message storage and streaming, including supported reconnect and cancellation behavior. The application supplies tools, prompt context, and result components. [Cloudflare chat agents](https://developers.cloudflare.com/agents/communication-channels/chat/chat-agents/)

## Financial tools

Read operations cover selected transactions, source evidence, historical comparisons, commitments, and deterministic scenarios. They call the same API used by the UI, with the same money and coverage rules. The model does not calculate official totals from descriptions or keep its own financial database.

A selected transaction or chart supplies explicit scope. A question with missing scope can ask a clarification. A question outside available tools receives a clear limitation rather than an invented result or generated computation service.

## User decisions

Suggested corrections lead to the existing edit control or explicit confirmation card. The normal authenticated API command checks current versions and financial invariants. Read-only tools keep conversational interpretation separate from authority to change records.

## Conversation and notes

Returning to a conversation shows persisted messages. If an answer failed, the user can ask again. SDK reconnect support is used where available without a guarantee of recovery from a particular model step.

Explicit notes provide durable context. After changing or removing a note, continue in a fresh conversation so the old transcript is not silently reused. Earlier conversations remain inspectable. [AI functionality](/technical/ai-functionality#memory) defines this flow.

## Evidence and privacy

Tool results show calculation time, query scope, exact values, and relevant source links. Older answers retain their text and displayed results; opening a live query uses current records. The app does not promise to reconstruct every historical database state.

Bank text, notes, and model output cannot redefine permissions. Logs contain operation IDs, timings, and safe failures, without raw financial text. [Operations](/technical/operations) owns access and provider disclosures.
